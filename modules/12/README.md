# Module 12 — Practical judgment and wrap-up

Assess the complete capstone workflow and decide how to use Copilot proportionately at work. Participants identify which tasks benefited from assistance, where human judgment and authorization remained essential, and a small set of team practices worth adopting.

## Materials

- `participant-guide.md` — individual reflection, capstone assessment, and team-practice selection.
- `prompts.md` — prompts for evidence-based reflection and a concise team practice proposal.
- `trainer-notes.md` — facilitation plan, assessment rubric, and discussion guidance.
- `capstone-assessment-checklist.md` — printable/fillable checklist for evaluating the capstone workflow.

## Project progression

This is a reflection and practice-selection module. It does not add or modify application code, dependencies, Skills, Hooks, MCP servers, GitHub workflows, or cloud configuration. Participants assess the tools and safeguards already used, including the Module 2 audit Hook, the Skills and delivery agent from Module 9, and the CI workflow from Module 10.
