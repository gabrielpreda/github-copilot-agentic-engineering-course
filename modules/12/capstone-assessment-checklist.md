# Capstone assessment checklist

Use one copy per participant or group. Mark each item **evidence shown**, **reported only**, **not applicable**, or **missing**.

## Traceability

- [ ] Product/design source identified; decisions distinguished from assumptions.
- [ ] Approved requirements linked to Jira stories and acceptance criteria.
- [ ] Each delivered criterion maps to implementation and verification evidence.
- [ ] Deferred or unresolved work is visible with a reason/owner.

## Engineering evidence

- [ ] Existing code path and behavior were inspected before change.
- [ ] Focused tests cover new behavior and important regression cases.
- [ ] Final diff is focused and reviewed for unintended/security/dependency changes.
- [ ] Exact local commands and results are recorded.
- [ ] GitHub Actions run is tied to the relevant commit/PR head; failures are not hidden.
- [ ] PR review, merge, and Jira status match actual observed state.
- [ ] Runtime/deployment checks are recorded, or deployment is clearly marked not performed.
