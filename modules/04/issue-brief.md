# Trainer-prepared GitHub Issue — add task priority

## Title

Clarify requirements for task priority

## Body

We need a way for the team to prioritize work. Add priority to tasks so users can see what is urgent. Keep it simple.

Before changing code, help turn this request into requirements. First inspect the current Task API behavior and search this repository's issues for related work. Identify what the request says explicitly, what the existing project already does, and what remains ambiguous. Ask focused questions before drafting acceptance criteria. Do not edit application files or create, update, or close GitHub issues.

The intended outcome of this exercise is a **draft** requirements worksheet with evidence, assumptions, acceptance criteria, non-goals, open questions, and a status. Do not silently decide product behavior where evidence is missing.

## Trainer setup
