# Module 8 — Review and basic engineering safeguards

Inspect a Copilot-assisted change before opening a pull request. Review the diff against the request and tests, check for unintended changes and missed requirements, and use branch, CI, and security safeguards to improve the change.

## Materials

- `participant-guide.md` — review workflow and hands-on exercise.
- `prompts.md` — review, triage, and correction prompts.
- `trainer-notes.md` — exercise answer key and facilitation guidance.
- `review-exercise/` — deliberately imperfect example patch and its issue brief. The patch is for inspection; do not apply it to the shared Target project.

## Project progression

Continue on the Module 7 feature branch. Review against the selected track's approved requirements, spec, tasks, and tests. This module adds no Target-project overlay or dependency. Fix findings on the same branch, rerun relevant checks, and prepare a clear handoff for the later pull-request module. Do not merge or publish the branch here.
