# Module 5 — Lightweight Spec-Driven Development

Use the reviewed Module 4 requirements and Miro evidence to create a concise feature specification and a short, dependency-ordered story/task list. Keep each item traceable to one or more acceptance criteria and identify the test evidence that will verify it. Prepare the reviewed items for Jira entry and record scope changes in both artifacts.

## Materials

- `participant-guide.md` — lab sequence, review steps, and completion criteria.
- `prompts.md` — prompts to create and revise the spec and task list.
- `trainer-notes.md` — facilitation, scope-change exercise, and reference outcome.
- `target-overlays/skill/` — reusable spec-and-task-planning Skill to **ADD** alongside existing Skills.
- `target-overlays/templates/` — concise specification and task-list templates to **ADD** to the Target project.

## Progression

Module 5 uses Module 4's requirements worksheet and Miro evidence, and carries forward the Module 2/3/4 Skills, MCP connections, and Hooks. It produces the reviewed story set that learners create in Jira and implement sequentially in Modules 6 and 9. This module introduces one new Skill and local planning artifacts. No application code is changed.

The artifacts are planning aids, not approval or implementation instructions that outrank the requester. Module 6 will use the reviewed tasks to guide incremental implementation.
