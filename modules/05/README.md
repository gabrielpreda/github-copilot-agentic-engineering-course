# Module 5 — Lightweight Spec-Driven Development

Use the reviewed Module 4 requirements to create a concise feature specification and a short task list. Keep each task traceable to one or more acceptance criteria and identify the test evidence that will verify it. Record scope changes in both artifacts.

## Materials

- `participant-guide.md` — lab sequence, review steps, and completion criteria.
- `prompts.md` — prompts to create and revise the spec and task list.
- `trainer-notes.md` — facilitation, scope-change exercise, and reference outcome.
- `target-overlays/skill/` — reusable spec-and-task-planning Skill to **ADD** alongside existing Skills.
- `target-overlays/templates/` — concise specification and task-list templates to **ADD** to the Target project.

## Progression

Module 5 uses Module 4's requirements worksheet and carries forward the Module 2/3/4 Skills, MCP connections, and Hooks. Use GitHub MCP to retrieve the agreed Issue context if needed; the Module 4 Miro extension is optional and only relevant when design evidence affected requirements. This module introduces one new Skill and local planning artifacts. It does not add a new MCP server or Hook because neither would add a distinct, useful capability to this specification exercise. No application code is changed.

The artifacts are planning aids, not approval or implementation instructions that outrank the requester. Module 6 will use the reviewed tasks to guide incremental implementation.
