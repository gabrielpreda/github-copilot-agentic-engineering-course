# Trainer Issue — Team Planning combined track

## Title

Capstone: add deadlines and labels to team tasks

## Body

Teams need to plan work against dates and organize it by project or workstream. Add optional due dates and labels to tasks, and provide useful filtered task views. Keep existing clients working.

Before implementation, inspect the current Task API and related issues, clarify date and label behavior, and write requirements, a concise specification, and a linked task plan. Build one focused end-to-end vertical slice on a feature branch; identify any second capability that is deferred. Preserve existing behavior and keep the current in-memory service; do not add a database, UI, or authentication in this exercise.

This combined track requires trainer approval. The Issue is a request source, not permission to skip clarification or implement all possible behavior at once.
