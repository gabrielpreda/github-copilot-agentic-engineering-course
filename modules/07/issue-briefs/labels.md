# Trainer Issue — labels and filtered views

## Title

Capstone: organize tasks with labels

## Body

Teams need to organize tasks by project or workstream. Add labels to tasks and let users view tasks with a chosen label. Existing tasks and clients must continue to work.

Before implementation, inspect the current Task API and related issues, clarify label limits, normalization, and matching behavior, and write requirements, a concise specification, and a linked task plan. Build a focused vertical slice on a feature branch. Preserve existing behavior and keep the current in-memory service; do not add a database, UI, or authentication in this exercise.

This Issue is the request source for the Module 7 capstone. It is not permission to skip clarification or expand scope beyond the trainer-approved answers.
